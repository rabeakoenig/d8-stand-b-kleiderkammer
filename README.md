# Kleiderkammer Eichgrund

Eine kleine Seite der Kleiderkammer (erfundenes Beispiel): Familien tragen ihren Termin ein.

## Starten

1. Den Ordner herunterladen.
2. Die Datei `app/index.html` im Browser öffnen. Die Einträge bleiben im Browser dieses Geräts.
3. Der Kasten „Frag die Kleiderkammer“ erscheint nur auf der veröffentlichten Adresse, wenn bei Netlify die Variable `KLEIDERKAMMER_KEY` gesetzt und neu veröffentlicht wurde. Der Wert gehört nie ins Repo.

## Regeln

- Jede Familie trägt einen Termin ein.
- Die Einträge bleiben im Browser des Geräts, eine Frage im Kasten geht an die Funktion bei Netlify und an einen KI-Dienst.

## KI-Hinweis

Der Kasten ist als KI gekennzeichnet.

## Grenzen

Prototyp mit erfundenen Daten, nicht rechtlich geprüft.
